JavaScript BOM

Объектная модель браузера - Browser Object Model (BOM) — это ядро JavaScript в вебе. BOM предоставляет объекты, раскрывающие функциональность веб-браузера.

Раздел 1. Window

  • Window — понятие объекта window
  • Alert — отображение диалогового окна оповещения.
  • Confirm — отображение модального диалогового окноа с вопросом.
  • Prompt — предложение пользователю ввести текст.
  • setTimeout — устанавливает таймер и выполняет функцию обратного вызова по истечении времени таймера.
  • setInterval — многократное выполнение функции обратного вызова с фиксированной задержкой между каждым вызовом.

Раздел 2. Location

  • Location — управление местоположением документа с помощью объекта location.
  • Получение параметров строки запроса — узнайте, как получить параметры строки запроса.
  • Перенаправление на новый URL-адрес — изучите, как выполнить перенаправление на новый URL-адрес с помощью JavaScript.

Раздел 3. Navigator

  • Navigator — запрос информации и возможностей браузера с помощью объекта navigator.

Раздел 4. Screen

  • Screen — получите информацию об экране, на котором запущен браузер, используя объект screen.

Раздел 5. History

  • History — управление стеком истории веб-браузера с помощью объекта history.
